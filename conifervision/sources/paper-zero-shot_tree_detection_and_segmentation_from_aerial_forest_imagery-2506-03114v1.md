# Zero-Shot Tree Detection and Segmentation from Aerial Forest Imagery

## Summary

This paper investigates the efficacy of using the **Segment Anything Model 2 (SAM2)** in a zero-shot manner for individual tree detection and segmentation from aerial RGB imagery. The authors evaluate a pretrained SAM2 model (using the Hiera-L image encoder) on two primary tasks: (1) standalone zero-shot segmentation using SAM2's automatic mask generator, and (2) zero-shot transfer by prompting SAM2 with bounding box predictions from an existing tree detection model ([[sources/paper-optimizing_aerial_imagery_collection_and_processing_parameters_for_drone-based_individual_tree_mapping_in_structurally_complex_conifer_forests|DeepForest]]). 

The models are benchmarked against CNN-based baselines (DeepForest and Detectree2) using three datasets: Emerald Point (California), NEON TreeEvaluation (USA), and Detectree2 (Malaysia). The results show that while standalone SAM2 tends to over-segment (leading to low precision but comparable recall), prompting SAM2 with bounding boxes from specialized detectors like DeepForest creates a powerful synergy, combining robust detection with highly detailed, zero-shot boundary delineation.

## Key claims

* **Generalization to Unseen Perspectives:** Standalone SAM2 generalizes exceptionally well to oblique aerial perspectives and varied forest densities (e.g., Emerald Point dataset), capturing smaller and shorter trees that specialized models like DeepForest and Detectree2 miss due to their training on top-down orthomosaics (p. 3).
* **Over-segmentation in Standalone Mode:** Without prompts, SAM2's automatic mask generator tends to over-segment, yielding low precision (0.17 on NEON, 0.16 on Detectree2) but competitive recall (0.41 on NEON, 0.65 on Detectree2) at an IoU threshold of 0.4 (p. 3, Table 1).
* **Synergistic Prompting:** Prompting SAM2 with bounding boxes generated by specialized detectors (e.g., DeepForest) resolves the over-segmentation issue, transferring domain-specific detection capabilities into high-quality, zero-shot boundary masks (p. 2).
* **Post-Processing Necessity:** Running SAM2 on cropped image sections and applying standard post-processing to remove disconnected regions significantly improves segmentation quality on large-scale aerial imagery (p. 2).

## Implications for our pipeline

* **Enhancing DINOv3 Species Classification:** Our current [[project/pipeline-overview|species classification pipeline]] relies on cropping detected trees. Integrating a SAM2-based boundary refiner prompted by our [[methods/deimv2-canopy|DEIMv2 canopy detections]] could provide precise, background-free tree crown masks instead of simple bounding box crops. This would eliminate background noise (soil, shadow, understory) before feeding feature vectors into [[methods/dinov3-classification|DINOv3]].
* **Alternative to Pseudo-Tree Crowns:** Instead of geometric reprojections like [[concepts/pseudo-tree-crown|pseudo-tree crowns (PTC)]], using a DeepForest/DEIMv2 + SAM2 pipeline could offer a purely data-driven way to isolate individual tree crowns from oblique or orthophoto drone patches.
* **Polygon-based NMS:** The paper highlights that applying Non-Maximum Suppression (NMS) directly to polygon representations (with an IoU threshold of 0.05) retains more valid detections than bounding box NMS, which could improve our [[methods/merge-detections|detection merging stage]].

## Replication pseudocode

### Prerequisites

* PyTorch and the `sam2` library (configured with the `sam2_hiera_l.yaml` config and `sam2_hiera_large.pt` pretrained weights).
* DeepForest installed (`pip install deepforest`).
* OpenCV, Rasterio, or Shapely for handling spatial imagery and polygon operations.

### Procedure

```text
# High-level steps for DeepForest-prompted SAM2 segmentation

1. Load the input aerial RGB image (or cropped tile).
2. Initialize the DeepForest model and predict bounding boxes:
   df_model = deepforest.main()
   df_model.use_release()
   boxes = df_model.predict_image(image=input_image)

3. Initialize the SAM2 Predictor:
   sam2_model = build_sam2(model_cfg, checkpoint, device='cuda')
   predictor = SAM2ImagePredictor(sam2_model)
   predictor.set_image(input_image)

4. For each predicted bounding box from DeepForest:
   a. Format the box as [x_min, y_min, x_max, y_max].
   b. Prompt SAM2 to generate the mask:
      masks, scores, _ = predictor.predict(
          box=box_coords,
          multimask_output=False
      )
   c. Select the highest-scoring mask.

5. Post-process masks:
   a. Remove disconnected components/islands.
   b. Convert masks to polygon coordinates.

6. Apply Polygon-based Non-Maximum Suppression (NMS) with an IoU threshold of 0.05 to filter overlapping crowns.
```

### Gaps / not specified in paper

* **Cropping Parameters:** The paper mentions running the model on "cropped sections" due to the large-scale format of aerial imagery (p. 2), but does not specify the exact tile size, overlap, or stride used during tiling.
* **Disconnected Component Threshold:** The exact threshold or algorithm used to "remove disconnected regions" during post-processing is not detailed.
* **Confidence Thresholds for Prompting:** While they mention a minimum confidence threshold of 0.1 for benchmarking (p. 3), the optimal confidence threshold for filtering DeepForest boxes before prompting SAM2 is not explicitly defined.

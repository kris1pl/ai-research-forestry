# TreeFlow: Conditional Flow Matching for 3D Tree Point Cloud Generation from Inventory Attributes

## Summary

TreeFlow is a conditional generative model that synthesizes realistic 3D individual-tree point clouds from scalar forest inventory attributes: species, acquisition platform (TLS, MLS, ULS), and tree height. Instead of relying on traditional parametric geometric envelopes (e.g., ellipsoids, cylinders) which fail to capture natural structural irregularities, TreeFlow uses a **Conditional Flow Matching (CFM)** framework with a **U-ViT transformer backbone** (28.3M parameters). The model was trained on 17,707 manually segmented trees from the **FOR-species20K** benchmark dataset. The generated trees are structurally distinct yet morphologically plausible, matching or approaching real-tree baselines on five of six geometric similarity metrics, with the strongest performance observed for trees under 25 meters tall.

## Key claims

- **First Application of Flow Matching to 3D Trees:** TreeFlow is the first model to generate individual-tree point clouds conditioned on scalar inventory attributes using a model trained entirely on real laser scanning data (p. 3).
- **High Geometric Fidelity:** Generated trees are nearly indistinguishable from real trees of the same genus and height class, achieving a global Chamfer distance of 0.581 m compared to 0.559 m for the real-to-real intra-class baseline (p. 12).
- **Height-Dependent Performance:** Generation quality is highly dependent on tree height. Performance is strongest below 25 m and degrades at greater heights due to the height-normalization preprocessing scheme, which reduces effective spatial resolution for taller trees at a fixed point count (p. 17).
- **Robustness to Guidance Scale:** The model is highly stable across a wide range of classifier-free guidance (CFG) scales ($\omega \in [1.0, 4.5]$) (p. 22).
- **Low Degeneracy Rate:** Only 2.09% of the 20,336 generated samples were flagged as degenerate (where the stem-tracking algorithm's cubic spine fit diverged), with failures concentrated almost entirely in tall conifers over 25 m (p. 17).

## Implications for our pipeline

- **Synthetic Data Generation for Canopy Analysis:** TreeFlow can be used to generate highly realistic synthetic 3D tree point clouds to train or validate our [[methods/chm-detection]] and [[methods/deimv2-canopy]] models.
- **Bridge the Scale Gap:** By generating detailed 3D structures from simple inventory attributes (species, height), TreeFlow can populate landscape-scale forest digital twins using only sparse aerial inputs (such as heights from a [[concepts/canopy-height-model]]).
- **Alternative to PTC:** Instead of using 2D pseudo tree crowns ([[concepts/pseudo-tree-crown]]), we could potentially utilize fully reconstructed 3D point clouds generated by TreeFlow to extract structural features for species classification.
- **Resolution Limitation:** Because TreeFlow is limited to 16,384 points due to the $O(N^2)$ complexity of the transformer's self-attention mechanism, it cannot directly generate the ultra-high-density point clouds (>100k points) typical of raw TLS scans without future latent-space or sparse-attention modifications (p. 19).

## Replication pseudocode

### Prerequisites

- Python 3.10+, PyTorch 2.8.0+, and the `torchdiffeq` or `flow-matching` library.
- Preprocessed FOR-species20K dataset (normalized to origin, scaled by height to $[-1, 1]$ vertical extent, and subsampled to 16,384 points).
- Sinusoidal positional encoding module (NeRF-style frequency embeddings).

### Procedure

```text
# High-level generation and inference steps

1. Load trained TreeFlow U-ViT model checkpoint.
2. Define conditioning parameters:
   - species_id: Integer index for target species
   - platform_id: Integer index for acquisition platform (e.g., TLS, ULS, MLS)
   - target_height: Continuous float value (meters)
3. Preprocess conditioning:
   - Log-transform target_height and project through MLP to Rd.
   - Embed species_id and platform_id via learned embedding tables to Rd.
   - Set timestep t=0 and encode using sinusoidal embeddings.
4. Sample source noise x_0 ~ N(0, I) with shape (1, 16384, 3).
5. Define the velocity field function for the ODE solver:
   def velocity_field(t, x):
       # Apply Classifier-Free Guidance (CFG)
       v_cond = model(x, t, species_id, platform_id, target_height)
       v_uncond = model(x, t, null_species, null_platform, null_height)
       v = v_uncond + omega * (v_cond - v_uncond)
       return v
6. Integrate the velocity field from t=0 to t=1 using the Dormand-Prince (dopri5) adaptive ODE solver:
   x_1 = odeint(velocity_field, x_0, t_span=[0.0, 1.0], method='dopri5')
7. Denormalize the generated point cloud x_1:
   - Divide coordinates by 2.0.
   - Scale coordinates by target_height.
   - Translate back to original spatial coordinates if needed.
```

### Gaps / not specified in paper

- **Specific MLP Dimensions:** The exact hidden layer dimensions of the two-layer MLPs used for projecting the positional encodings, timesteps, and log-transformed heights are not explicitly detailed.
- **Null Embedding Initialization:** The exact initialization strategy for the learnable null embeddings used during classifier-free guidance dropout is TBD.
- **Exact Stratification Splits:** While the paper states that an 80/10/10 stratified split by species was used, the exact list of individual trees assigned to each split is not provided in the text (though available in the referenced GitHub repository).

## Quotes
